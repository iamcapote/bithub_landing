Setup Instructions

            
Follow these steps to configure MCP with Discourse

          

          
          

            

              
1

              

                
Generate Your Keys

                
Click the generate button above to create a new RSA key pair. Choose 4096-bit for maximum security.

              

            

            
            

              
2

              

                
Add Public Key to Discourse

                
Go to your Discourse Admin → Settings → MCP. Paste your public key in the designated field.

              

            

            
            

              
3

              

                
Configure MCP Server

                
Add your private key to your MCP server's environment configuration as MCP_PRIVATE_KEY.

              

            

            
            

              
4

              

                
Test Connection

                
Verify the integration by sending a test request from your MCP server to the Discourse endpoint.
